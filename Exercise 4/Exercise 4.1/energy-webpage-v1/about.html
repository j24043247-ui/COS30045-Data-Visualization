ABOUT THE PROJECT

About Us

Helping users understand appliance energy consumption through simple information.

OUR PURPOSE

Making Energy Information Easier to Understand

Power Appliances is a student website project focused on presenting introductory information about appliance electricity consumption in the Australian market.

The website combines informational content with an interactive JavaScript calculator so users can explore how appliance power and usage time affect estimated energy consumption.

Our Focus

  • Energy awareness
  • Appliance electricity use
  • Simple calculations
  • User-friendly web design

PROJECT GOALS

What This Website Demonstrates

01

HTML Structure

Three connected HTML pages demonstrate semantic structure, navigation, forms, content sections and accessible controls.

02

CSS Styling

A shared external stylesheet provides consistent colours, typography, spacing, responsive layout and interactive states.

03

JavaScript

Vanilla JavaScript provides the FAQ accordion, navigation behaviour, calculator calculations, validation and dynamic results.
