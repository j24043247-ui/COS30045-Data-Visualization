WHAT THIS DEMONSTRATES

From Data to SVG

The chart demonstrates the progression from creating an SVG canvas to loading CSV data, binding records to SVG rectangles and using D3 scales to make the visualisation fit its available space.

✓ D3 v7 is loaded separately from the existing JavaScript.
✓ CSV rows are converted into numeric count values.
✓ Each data record becomes one SVG rectangle.
✓ scaleLinear() controls bar width.
✓ scaleBand() controls bar position and thickness.
